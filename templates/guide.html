01 · ABSTRACT

Project at a glance

Smart Attendance is an academic prototype that combines computer vision and a convolutional neural network to demonstrate automatic attendance. An administrator enrolls each student using a university ID, captures face images through a camera, then trains and evaluates a CNN using a stratified train/test split. At check-in, OpenCV locates a face, the trained model predicts a student ID and SQLite stores one present record per student per day. An ID-based check-in remains available for reliable demonstration and review.

03 · CORE CONCEPTS

ML, ANN and CNN in this project

M

Machine learning

Machine learning lets a program learn patterns from examples. Here, labeled face crops and student IDs form the dataset. The model learns a mapping from visual patterns to a registered ID.

A

Artificial neural network

An ANN is made of connected layers of numerical units. Each unit combines its inputs, applies an activation function and passes the result forward. A CNN is a neural network architecture designed to handle image structure efficiently.

C

Convolutional neural network

Convolution filters learn local image features such as edges and shapes. Pooling reduces the feature map size; dense layers combine learned features into a student-ID prediction. CNNs are suited to images because they reuse filters across nearby pixels and retain spatial patterns.

ANN (dense network)CNN (image network)
Typically flattens input featuresUses shared convolution filters
Does not encode image neighborhoodsCaptures nearby visual patterns
Often needs more weights on imagesUses spatial structure more efficiently
04 · MODEL EVALUATION

Why split the dataset?

train_test_split separates examples into training and testing sets. The model fits on the training images; the held-out test images estimate how well it predicts examples it did not train on. A validation subset within the training portion helps track progress between epochs. This app uses a stratified split to keep each student represented on both sides, then reports training, validation and testing accuracy, loss, a confusion matrix, and precision/recall/F1.

AccuracyShare of test predictions that were correct.
LossHow far predicted class probabilities are from the true labels.
PrecisionHow often predicted matches for a student are correct.
RecallHow many test examples for a student were recognized.

IMPORTANT LIMIT

Use responsibly

This small teaching model is sensitive to lighting, camera position and dataset size. A predicted match can be wrong. Verify results during demonstrations; do not use this prototype as the sole source of official attendance.
